# Tish — фронтенд

Весь интерфейс приложения записи к стоматологу (Tish): **CRM** для сотрудников (компьютер и
Telegram), раздел **«Платформа»** для команды Tish, **самозапись пациента** в Telegram (ru/ky) и
**страницы сайта** (`/clinics`, `/c/<код>`, `/join`, `/go`). Бэкенд — репозиторий
[`subanovkanat321/dental`](https://github.com/subanovkanat321/dental), решения — его
`docs/adr/0001-web-crm.md` и `0002-frontend-migration.md`.

- React 19 + TypeScript + Vite, данные — TanStack Query, запросы — `openapi-fetch` с типами из
  контракта `api/openapi.json` (копия `docs/api/openapi.json` бэкенда).
- Адрес на проде — корень домена `/`: nginx отдаёт `index.html` (CRM, «Платформа», самозапись —
  что показать, решает ответ `/api/patient/me`) и `site/*.html` (страницы сайта со своими og:-тегами).
  Вход на сайте — виджет «Войти через Telegram» (cookie-сессия), в Telegram — подпись запуска.
- Разделы CRM и самозапись — отдельные lazy-чанки: пациент не скачивает CRM.

## Команды

Нужны Node.js 22.12+ и запущенный бэкенд на :8080 (в соседней папке `../dental`:
`./mvnw spring-boot:run`, нужны JDK 25 и Docker).

```bash
npm ci                 # зависимости
npm run dev            # http://localhost:5173/ — CRM; сайт: /site/clinics.html, /site/join.html …
npm test               # Vitest + Testing Library + MSW
npm run lint && npm run typecheck && npm run build
npm run api:sync       # контракт из ../dental/docs/api/openapi.json → api/openapi.json и src/api/schema.d.ts
```

**Вход на ноутбуке.** `npm run dev` входит сам: берёт подпись у бэкенда (`/dev/init-data`, есть
только в его профиле `local`) за первого из `ALLOWED_TELEGRAM_IDS` — по умолчанию пользователь 1,
админ клиники №1 и владелец платформы. Виджет «Войти через Telegram» на localhost не работает.
Бэкенд не в `local` (например, `java -jar` для e2e) — входа нет, `/` уводит на `/clinics`.
Посмотреть, что видит пациент или другой сотрудник, — в бэкенде `ALLOWED_TELEGRAM_IDS=<id>`.
Бэкенд на другом адресе — `DENTAL_BACKEND=http://localhost:8081 npm run dev`.

## Что готово

- [x] Каркас, CI, вход (401 → «Войти через Telegram»), раскладка: меню слева, рабочая область.
- [x] «Расписание»: день, все врачи колонками, статусы как в Mini App, карточка приёма справа (Esc — закрыть).
- [x] Действия в карточке: подтвердить заявку, «Приём состоялся», «Неявка», отменить; оплата
      (способ, «не всё сразу», «На кассу», «Принять оплату», доплата).
- [x] Запись кликом в пустое место колонки врача или «＋ Новая запись»: поиск пациента, новый пациент
      (+996, дубль номера — «Выбрать его»), услуга с длительностью, комментарий. Расписание
      обновляется раз в минуту.
- [x] «Пациенты»: таблица (последние 300 по визитам) с поиском по имени и номеру и сортировкой;
      нет среди них — поиск по всей клинике; карточка справа: был / неявки, долг, записи, история,
      «＋ Записать» → «Новая запись» в «Расписании». Разделы — в адресе (#/patients).
- [x] «Касса»: выручка за сегодня / неделю / месяц / свой период (по способам и по дням), выбор
      врача у админа; «К оплате на кассе» (регистратура) и долги таблицами — нажать строку,
      принять оплату или доплату в карточке справа.
- [x] «Склад»: таблица (заканчивается — сверху), поиск, «Только заканчивается», чей склад (при
      «своём складе у каждого врача»); карточка: списать, поставка с ценой, настройки, история;
      новый материал; пустой склад — «Типовой набор».
- [x] Телефон и узкое окно: меню — панелью внизу, карточки — на весь экран, таблицы и колонки
      врачей прокручиваются вбок.
- [x] Медкарта («Пациенты» → карточка → «🦷 Медкарта и снимки»): карта зубов по FDI (16 в ряд,
      заметка — подсказкой), план лечения с суммой и «сделано», заметки о визитах, снимки —
      просмотр и загрузка с компьютера (сжатие до 2560 px и миниатюра, как в приложении).
- [x] Карточка приёма: перенести (день, время, длительность) или передать другому врачу, сменить
      услугу, комментарий; материалы на приёме — списать со склада, ещё −1, вернуть.
- [x] CRM в Telegram (ADR 0002 бэкенда): открытая из бота, входит по подписи initData
      (`Authorization: tma …`), «Назад» Telegram закрывает карточку; в старом Mini App — «Новая CRM (бета)».
- [x] Этап 2 ADR 0002 — недостающие экраны персонала: лист ожидания, профосмотры, статистика.
- [x] «Настройки» (шестерёнка, `src/settings`) вместо разделов «Команда», «Клиника», «Аккаунт»:
      пункты группами — часы работы, перерывы, услуги, врачи, сотрудники, «О клинике», анкета,
      новости, тариф и оплата, договор, данные, мой профиль, техподдержка, новости стоматологии,

- [x] Телефон, «Все врачи»: день списком, у каждого врача свой блок.
