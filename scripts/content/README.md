# Контент-план Instagram

`gen-plan.mjs` рисует картинки плана и пишет `public/content/plan.json`; тексты, даты, подписи и
сценарии рилсов — в `plan-data.mjs`. Файлы попадают на сайт со сборкой: `https://tish.kg/content/…`.
Проверка плана — тест `src/platform/contentPlan.test.ts` (правила импорта бэкенда, картинки на месте).

```bash
node scripts/content/gen-plan.mjs            # → public/content (старые ГГГГ-ММ-ДД-*.png удаляются)
node scripts/content/gen-plan.mjs /tmp/x     # или в свою папку
```

Нужны Playwright с Chromium (по умолчанию `../dental/e2e/node_modules`, или `PLAYWRIGHT=…/index.mjs`),
шрифты из `node_modules/@fontsource` и `pngquant` или Python с Pillow для сжатия.

## Стиль

Белый фон, один акцент — бирюзовый `#0E8A80`, текст `#0F2A30`; Geologica 500/600 — заголовки,
Golos Text — текст. Поля 96 px, одинаковые шапка (рубрика + логотип) и подвал (tish.kg + номер слайда).
Тишка — изредка и небольшой. Сторис: важное между 250 и 1580 px; рилс: в средней полосе 1080×1440.
Медицинские советы — только общие, с «Это не заменяет осмотр у стоматолога»; люди и клиники на макетах
вымышленные. Фразы для будущих постов — `docs/content-phrases.md`.

## Как попадает в приложение

Бэкенд после старта и каждый день в 09:30 забирает `plan.json` и добавляет посты, ключа которых
(«день + название») ещё не было (`ContentAutoImport`, таблица `content_import_key`). Уже загруженные
посты он не обновляет и не удаляет: заменили план — старые посты удалите в «Платформа → Контент»,
а исправления существующих загрузите кнопкой «Загрузить готовый план» (обновляет по «день + название»).
